# Earlier naming screen

**Historical shortlist:** Kesten subsequently superseded these proposals, and Kerquant later superseded Kesten. Keep this screen as research history. Current identity and screening limits are recorded in [the Kerquant identity](../kerquant/IDENTITY.md); [KESTEN.md](KESTEN.md) retains the earlier decision and conflicts.

Screened 7 November 2026; documented 8 November 2026. At the time of this screen no name was approved or cleared; the neutral display labels were “Market workspace” and “Workspace”. The later Kesten selection above supersedes those defaults. Repository/package/database identifiers are unchanged.

The previous names, including Cadrisyn, Apertane and Basisfold, are not carried forward as recommendations. The brief is a rigorous market-analysis and reproducible research instrument, not a promise to predict returns.

## Visual and verbal concepts

**Ordelyt / instrument console.** Positioning: market analysis with inspectable evidence. Optional editorial line: “A clear view of the evidence.” Inter Variable for interface/wordmark studies; IBM Plex Mono for prices, dates and identifiers. Custom optical spacing around `ly`, with an open terminal on the `t`; no upward arrow or candlestick logo. Ink `#0D1116`, panel `#11171E`, pale type `#E3E8EC`, desaturated cyan `#8CBACB`, muted amber `#E2BD78`. Small outline icons with consistent stroke, explicit labels for consequential actions. Voice names the observation, method, horizon and limitation; never “AI-powered alpha”.

**Markovell / research instrument.** Positioning: repeatable quantitative work beside the market chart. Optional line: “Observe. Test. Reproduce.” A slightly wider wordmark with a small registration-point motif made from two offset rules, not an existing exchange/terminal symbol. Neutral graphite with blue-gray data series and a restrained violet secondary study. Numbers keep the same mono treatment. Voice is concise and analytical; no claim of model superiority or institutional adoption.

**Sessionfield / research folio.** Positioning: market history and research in one inspectable workspace. Optional line: “Every result has a record.” A quiet mixed-case wordmark and a field-frame motif using four incomplete corners. Warm paper light theme, charcoal dark theme, slate and ochre accents. The interface still uses Inter/IBM Plex; an editorial serif could be tested for long-form reports only, not shipped as an added dependency. Voice is concrete and observational.

Taglines are exploration material, not extra interface chrome. The implemented interface removes nonessential slogans.

## What was actually checked

- Bounded public exact-name and finance/software web queries for the candidates and rejected alternatives. This was an accessible search pass, not exhaustive coverage of every search engine or jurisdiction.
- Public GitHub repository name queries, limited to the returned first 30 results, then exact-name filtering. No claim about private repositories, organizations, handles, package registries or all pages.
- Public Verisign COM RDAP responses for each candidate. 404 means no record returned by this lookup at that time. It does **not** guarantee registrability, price or availability. No registrar checkout, reservation or purchase.
- [USPTO search entry point](https://www.uspto.gov/trademarks/search) was accessible. The interactive trademark system did not provide a reproducible candidate result set in this workflow. **No candidate has a completed trademark-registry search.** WIPO, Indian and other national/class/similarity searches remain unverified. No trademark clearance, certification or legal opinion is asserted.

Machine-readable observations, acquisition date, HTTP status and exact query URLs are retained in `brand-checks.json` beside this document. Each record identifies its actual scope. Repeat all checks before a name decision, then obtain appropriate legal review for intended markets and classes.

Follow-up search evidence includes the [Markovell surname in an EPA record](https://19january2021snapshot.epa.gov/sites/static/files/2017-03/documents/ec_wvd004336749.pdf), [SessionField in Microsoft's API documentation](https://learn.microsoft.com/en-us/dotnet/api/system.web.ui.webcontrols.sessionparameter.sessionfield?view=netframework-4.8.1), and [Statrium in a pharmaceutical product leaflet](https://pharmalist.gr/spc/PL_3072403_7.pdf). The latter changes Statrium's decision from hold to rejection. Public search is a screening instrument, not legal clearance.

## Rejected directions

Do not recommend a name merely because it sounds financial. The screen rejected existing software/product uses including [Outsample](https://outsample.com), [Evidora](https://evidora.io), [MarketMethod](https://marketmethod.io), [Methodry](https://methodry.com/), [FieldBasis](https://www.fieldbasis.app/) and [Orivect](https://www.orivect.com/challenges). Seriescope and Metraxis also showed software/app collisions; Talmere had an unrelated registered-business use. These are obvious-conflict exclusions, not trademark findings.
