# Cadrisyn implementation status

On 2026-11-06, the Phase-three source workflow passes local numerical, API and browser acceptance on `codex/cadrisyn-foundation`. Cadrisyn remains a temporary working name. No merge, deployment, purchase, registered domain, trading execution or certification occurred.

The running source preview is [forecast research](http://127.0.0.1:3000/app/research), with [markets](http://127.0.0.1:3000/app/markets) and [account security](http://127.0.0.1:3000/app/account). API liveness/readiness are on port 8000. The frontend is a production build; the backend uses the isolated development SQLite store. Existing analyst credentials stay in ignored `.local/credentials.json`. The container entry point on 8080 is unavailable because Docker cannot start on this host.

The private research workflow supports operator-approved immutable dataset imports, explicit synthetic fixture seeding, last-close and expanding historical-log-mean references, one/five-session targets, causal split handling, fixed chronological walk-forward evaluation, durable owner-private results and exact replay. The UI shows dataset history versus forecast paths, units, origin/cutoff/generation times, validation/test comparisons, direction counts, data rights and version/runtime evidence. It preserves charting, indicators, themes, watchlists and account/session behavior.

No suitable local rights- and availability-documented historical dataset was found. The delivered workflow uses an explicitly labelled synthetic fixture and establishes no empirical forecasting performance. Legacy BiLSTM/HPO, ARIMA/GARCH and RL are rejected for product promotion with documented source-level methodological blockers; their code, dependencies and artifacts remain preserved. No advanced model or probability interval is approved.

Four browser journeys use the real API and two isolate account UI states. TypeScript, ESLint, Python lint, optimized build and matching OpenAPI pass. Actual separate-target SQLite restoration, current-code replay and restored sign-in/private result access pass.
